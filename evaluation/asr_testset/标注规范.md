# ASR 方言测试集标注规范（v0）

## 用途
为 PRD 4.2 的 ASR 选型横向对比提供"真值参考文本"：各候选引擎（讯飞/商汤/阿里云等）转写同一批音频，与人工参考文本计算字错误率（CER），择优集成。当前 5 段门诊音频（山东口音）是唯一现成真实素材；住院场景补采录音到位后按同一规范扩充为测试集 v1。

## 转写规则
1. **逐字转写**：听到什么写什么（普通话字面），不概括、不改写、不纠错。
2. **说话人标注**：每行前加 `[医生]` 或 `[患者]`，按对话轮次分行；角色难判时写 `[?]`。
3. **方言词**：按发音用普通话近音字转写（如"俺"保留"俺"），后括号标注推测语义，如：俺这肚赛（肚子疼）。
4. **数字与计量**：统一用阿拉伯数字 + 中文单位，如 `血压 115/76`、`体温 36.5 度`、`吃了 3 天药`。
5. **医学术语**：能确定的标准术语按规范写法（如"反跳痛"），听不准写同音字并加 `（？）`。
6. **无意义音**：语气词（嗯、啊、呃）保留；无法辨析的片段写 `[听不清 xx:xx]` 并记录时间点。
7. **敏感信息**：转写文本如出现姓名/电话，保留（这是真值参考，仅存院内授权目录），但不得外传。

## 完成定义（DoD）
- 全部 5 段完成双人独立转写 → 交叉校对 → 一致率 ≥98% 后定稿。
- 定稿后运行选型脚本：`CER = edit_distance(引擎输出, 参考文本) / 参考文本长度`，按整体/医生/患者、普通话/方言段分别统计。
